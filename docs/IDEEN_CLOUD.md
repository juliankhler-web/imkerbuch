# Ideen für die Cloud (später, nicht in Version 1.0)

## Zeiterfassung für Mitarbeiter mit Gehaltsstruktur (Julian 01.11.2026)

Idee: Mitarbeiter buchen ihre Zeiten, dazu eine Gehaltsstruktur je Person.

Einschätzung:
- Passt zur Cloud, weil mehrere Personen an denselben Daten arbeiten. Allein auf einem Handy geht das nicht.
- Zielgruppe sind Betriebe mit Angestellten, also eher eine höhere Abo-Stufe als das Grundabo.
- Reihenfolge: zuerst Cloud mit Team-Zugang, danach Mitarbeiter-Zeiten am Stand, danach Stundensätze und Kosten je Volk oder Charge.
- Keine Lohnabrechnung bauen. Stattdessen Stunden und Sätze als Datei für Steuerberater oder Lohnbüro ausgeben.

Vorher klären (Anwalt, Steuerberater):
- Gehalts- und Arbeitszeitdaten von Beschäftigten: Datenschutz, Auftragsverarbeitung, wer was sehen darf.
- Aufbewahrung und Nachweise, zum Beispiel beim Mindestlohn.
